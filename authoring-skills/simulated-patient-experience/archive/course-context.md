# Level 2 course context

Accept an existing syllabus, course description, assignment materials or faculty explanation. Extract profession/program, learner stage, relevant objectives, expected responsibilities, prerequisites, permitted resources and named assessment instruments with source locations.

Map the proposed experience to the supplied objectives. Separate explicit requirements from suggested alignment. A course name such as FNP does not establish a specific syllabus, current prescribing authority, grading standard or required workflow. Do not invent a syllabus when none is available.

Keep clinical case facts stable. If the task or expected scope conflicts with the case's supplied findings, document the mismatch for faculty resolution. A single case need not cover every course objective.

Return a short course-context profile and alignment table. Missing documents may remain unresolved during authoring; do not represent inferred objectives as faculty-approved requirements.
